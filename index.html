P1 Monitor

A live web display for your smart electricity meter — read locally through a GreenHESS ADA P1 Meter, with optional Fronius inverters. Nine hand-made skins, synthesized sound, no cloud.

Élő webes kijelző az okos villanyórádhoz — helyben olvasva egy GreenHESS ADA P1 Meteren át, opcionálisan Fronius inverterekkel. Kilenc kézzel készített skin, szintetizált hangok, felhő nélkül.

What it shows

Mit mutat

Live power flowÉlő energiafolyam

Grid import / export, house consumption and solar production — per inverter, updated every few seconds.

Hálózati vétel / betáp, házfogyasztás és napelemes termelés — inverterenként, pár másodpercenként frissítve.

Phases and quarter hourFázisok és negyedóra

Voltage, current and power on L1–L3, the projected 15-minute average, tariff and meter totals.

Feszültség, áram és teljesítmény L1–L3-on, a várható negyedórás átlag, tarifa és mérőállások.

Daily totals and historyNapi összesítők, előzmény

Today's consumption, production, import and export, plus 6 hours of history as plotters, barographs and bar graphs.

Mai fogyasztás, termelés, vétel és betáp, és 6 óra előzmény szalagíróként, barográfként, oszlopokként.

Private by designAdatvédelem

Everything stays on your network. The reader's cloud username and password are dropped immediately; history lives in RAM only.

Minden a saját hálózatodon marad. Az olvasó felhős felhasználónevét és jelszavát azonnal eldobja; az előzmény csak RAM-ban van.

What you need

Mi kell hozzá

  • A GreenHESS ADA P1 Meter on the meter's P1 port, connected to your Wi-Fi (its local JSON API reachable on your network)
  • Optional: Fronius inverter(s) with Solar API enabled
  • An always-on computer on the same network — e.g. a Raspberry Pi — with Python 3.8+ (nothing else to install)
  • Any modern browser, desktop or phone
  • GreenHESS ADA P1 Meter a mérő P1 portján, a Wi-Fi-re csatlakoztatva (a helyi JSON felülete elérhető a hálózaton)
  • Opcionálisan Fronius inverter(ek), bekapcsolt Solar API-val
  • Egy folyamatosan működő gép ugyanazon a hálózaton — pl. Raspberry Pi — Python 3.8+ verzióval (más nem kell)
  • Bármilyen mai böngésző, gépen vagy telefonon

Quick start

Gyors indulás

git clone https://github.com/gali-master/P1-Monitor.git
cd P1-Monitor
cp config.example.json config.json
nano config.json          # address of your P1 reader and invertersa P1 olvasó és az inverterek címe
python3 p1monitor.py      # then open http://<server-ip>:8080/utána: http://<szerver-ip>:8080/

⚠️ The raw /json answer of the P1 reader contains your cloud username and password — never paste it anywhere public. The full guide covers finding the addresses, autostart with systemd and all settings.

⚠️ A P1 olvasó nyers /json válasza tartalmazza a felhős felhasználóneved és jelszavad — sehova ne másold be nyilvánosan. A teljes leírás mutatja a címek kiderítését, az automatikus indítást systemd-vel és minden beállítást.
